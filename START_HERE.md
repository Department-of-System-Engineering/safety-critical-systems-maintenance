# Kezdés böngészőből

A kurzus elsődleges tananyaga a [`course/`](course/) mappában található 12 strukturált Jupyter notebook.

## Futtatás telepítés nélkül

1. GitHubon kattints a **Code** gombra.
2. Válaszd a **Codespaces** fület.
3. **Create codespace on main**.
4. A böngészős VS Code-ban nyisd meg a `course/01_BIZTONSAGKRITIKUS_ALAPOK.ipynb` fájlt.
5. Válaszd a Python kernelt, majd **Run All** vagy haladj cellánként.

Ajánlott sorrend: `01` → `12`. Minden notebook magyarázó tananyag, képletek, lépésről lépésre felépített kód, eredményértelmezés, TK-101 alkalmazás és **Próbáld ki!** feladatok kombinációja.

A Quarto csak publikációs/export réteg; a tananyag elsődleges forrása a notebook.
